☁ Google Drive Cloud Sync

Shared-folder model: Each QA Manager signs in with their own Google account. All data lives in one shared folder on the owner's Drive. No more sharing passwords.
📋 One-time setup steps (for Sanjiv / owner)
  1. Open drive.google.com logged in as velite@velite.in.
  2. Click New → New folder and name it Velite QA Nexus — Shared Data.
  3. Right-click the folder → Share. Add each QA Manager's Google email (Ramna, Satwinder, etc.) with role Editor. Send.
  4. Open the folder. Copy its ID from the URL — the long string after /folders/.
    e.g. for drive.google.com/drive/folders/1A2b3C4d5E6f7G8h9I, the ID is 1A2b3C4d5E6f7G8h9I.
  5. Paste the ID below and click Save Settings.
  6. Email the ID to each QA Manager — they each paste it once here on their own machine.
